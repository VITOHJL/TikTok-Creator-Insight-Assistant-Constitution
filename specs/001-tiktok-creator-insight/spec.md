# Feature Specification: TikTok Creator Insight Assistant MVP

**Feature Branch**: `001-tiktok-creator-insight`  
**Created**: 2025-01-27  
**Status**: Draft  
**Input**: User description: "构建一个TikTok Creator Insight Assistant MVP，帮助短视频创作者将创意意图转化为结构化脚本大纲与趋势洞察。支持多语言输入、生成3种不同风格的脚本、5-10个Hashtag和音乐风格建议，并提供卡片式结构化展示。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 创意意图输入与识别 (Priority: P1)

创作者打开应用，在输入界面输入他们的创作主题或目标赛道（支持中文或英文），系统识别并理解用户的创意意图。

  **Why this priority**: 这是整个应用的核心入口，没有输入功能，后续的AI生成功能无法工作。这是MVP的最小可行功能。

**Independent Test**: 可以独立测试：用户输入文本后，系统能够正确接收、显示并准备处理输入内容。即使没有AI生成功能，输入界面本身也能展示价值（用户可以看到自己的输入被正确记录）。

**Acceptance Scenarios**:

1. **Given** 用户打开应用，**When** 用户在输入框中输入创作主题（如"美食探店"），**Then** 系统显示用户输入的文本，并准备提交处理
2. **Given** 用户输入英文内容（如"food review"），**When** 用户提交输入，**Then** 系统能够识别并处理英文输入
3. **Given** 用户输入中文内容（如"旅行vlog"），**When** 用户提交输入，**Then** 系统能够识别并处理中文输入
4. **Given** 用户输入目标赛道（如"美妆"），**When** 用户提交输入，**Then** 系统能够识别赛道信息并准备生成相关内容

---

### User Story 2 - AI生成短视频脚本大纲 (Priority: P1)

用户提交创作主题后，系统调用AI模型生成3个不同风格的短视频脚本结构，以卡片形式展示给用户。

**Why this priority**: 这是产品的核心价值主张 - 将创意转化为结构化脚本。没有这个功能，产品无法解决"创意枯竭"的痛点。

**Independent Test**: 可以独立测试：用户输入主题后，系统调用AI API，返回3个不同风格的脚本大纲，并以卡片形式展示。即使没有Hashtag和音乐建议，脚本生成本身也能提供价值。

**Acceptance Scenarios**:

1. **Given** 用户已输入创作主题并提交，**When** 系统调用AI API生成脚本，**Then** 系统返回并展示3个不同风格的脚本大纲（例如：故事型、教程型、对比型）
2. **Given** 系统正在生成脚本，**When** API调用进行中，**Then** 用户界面显示Loading状态，提示"正在生成脚本..."
3. **Given** 脚本生成完成，**When** 系统收到AI响应，**Then** 3个脚本大纲以卡片形式展示，每个卡片包含脚本结构要点
4. **Given** 用户查看脚本卡片，**When** 用户点击"一键复制"按钮，**Then** 对应脚本的内容被复制到剪贴板，用户收到复制成功提示

---

### User Story 3 - Hashtag与音乐风格建议生成 (Priority: P2)

系统基于用户输入的创作主题，生成5-10个高潜力Hashtag标签和背景音乐风格描述建议。

**Why this priority**: 这是增强功能，帮助创作者提升内容曝光度。虽然重要，但可以在脚本生成功能之后实现，不影响核心MVP价值。

**Independent Test**: 可以独立测试：用户输入主题后，系统生成Hashtag和音乐建议，以独立卡片或区域展示。即使脚本生成失败，Hashtag和音乐建议仍可独立提供价值。

**Acceptance Scenarios**:

1. **Given** 用户已输入创作主题，**When** 系统生成内容建议，**Then** 系统返回5-10个相关的Hashtag标签
2. **Given** 系统生成Hashtag建议，**When** 展示给用户，**Then** Hashtag以可点击或可复制的形式展示
3. **Given** 系统生成音乐建议，**When** 展示给用户，**Then** 系统提供背景音乐风格描述（如"轻快节奏"、"舒缓背景音"等），不包含实际音乐文件
4. **Given** 用户查看Hashtag建议，**When** 用户点击复制按钮，**Then** 所有Hashtag被复制到剪贴板

---

### Edge Cases

- **空输入处理**: 当用户提交空输入或仅包含空白字符时，系统显示友好的错误提示，要求用户输入有效内容
- **API调用失败**: 当AI API调用失败（网络错误、超时、认证失败）时，系统显示用户友好的错误消息，提供重试选项
- **API响应超时**: 当API响应时间超过30秒时，系统显示超时提示，允许用户取消或重试
- **部分内容生成失败**: 当脚本生成成功但Hashtag生成失败时，系统仍展示已成功生成的内容，并提示部分功能暂时不可用
- **输入内容过长**: 当用户输入超过500字符时，系统提示输入过长，建议精简内容
- **特殊字符处理**: 当用户输入包含特殊字符或emoji时，系统能够正确处理并传递给API
- **多语言混合输入**: 当用户输入中英文混合内容时，系统能够识别并处理

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 提供简洁的文本输入界面，支持用户输入创作主题或目标赛道
- **FR-002**: 系统 MUST 支持中文和英文两种语言的输入识别和处理
- **FR-003**: 系统 MUST 在用户提交输入后，调用AI模型API生成内容
- **FR-004**: 系统 MUST 生成3个不同风格的短视频脚本大纲（风格差异必须明显，如：故事叙述型、教程教学型、对比评测型）
- **FR-005**: 系统 MUST 生成5-10个与主题相关的高潜力Hashtag标签
- **FR-006**: 系统 MUST 生成背景音乐风格描述建议（文字描述，不包含实际音频文件）
- **FR-007**: 系统 MUST 使用卡片式布局展示所有生成的内容（脚本、Hashtag、音乐建议）
- **FR-008**: 系统 MUST 在API调用过程中显示Loading状态指示器
- **FR-009**: 系统 MUST 实现错误处理机制，当API调用失败时显示友好的错误消息
- **FR-010**: 系统 MUST 为每个生成的内容卡片提供"一键复制"功能
- **FR-011**: 系统 MUST 在内容复制成功后向用户显示确认提示
- **FR-012**: 系统 MUST 验证用户输入不为空且长度合理（建议1-500字符）
- **FR-013**: 系统 MUST 集成阿里云百炼平台API（使用DeepSeek-V3、DeepSeek-R1或Qwen-Max模型）
- **FR-014**: 系统 MUST 安全存储API密钥，使用环境变量管理，不将密钥提交到版本控制

### Key Entities *(include if feature involves data)*

- **创作请求 (CreationRequest)**: 代表用户的一次创作意图输入，包含：输入文本、语言类型（中文/英文）、提交时间戳
- **脚本大纲 (ScriptOutline)**: 代表AI生成的一个脚本方案，包含：脚本风格类型、结构化要点列表、生成时间
- **Hashtag建议 (HashtagSuggestion)**: 代表一个Hashtag标签建议，包含：标签文本、相关度评分（可选）
- **音乐风格建议 (MusicStyleSuggestion)**: 代表音乐风格描述，包含：风格描述文本、适用场景说明（可选）
- **生成结果 (GenerationResult)**: 代表一次完整的AI生成结果，包含：3个脚本大纲、5-10个Hashtag、1个音乐风格建议、生成状态（成功/失败/部分成功）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在30秒内完成从打开应用到提交创作主题的完整输入流程
- **SC-002**: 系统在用户提交输入后，能够在15秒内完成AI API调用并返回生成结果（在正常网络条件下）
- **SC-003**: 90%的API调用能够成功返回完整的生成内容（3个脚本 + 5-10个Hashtag + 音乐建议）
- **SC-004**: 生成的脚本大纲必须包含至少3个结构化要点，每个脚本风格明显不同
- **SC-005**: 生成的Hashtag数量在5-10个之间，且与输入主题相关度达到80%以上（可通过人工评估）
- **SC-006**: 用户可以在5秒内完成复制任意生成内容到剪贴板的操作
- **SC-007**: 当API调用失败时，系统在3秒内显示错误提示，用户能够理解错误原因
- **SC-008**: 系统支持处理中英文混合输入，识别准确率达到95%以上
- **SC-009**: 在移动设备和桌面设备上，卡片式布局都能正常显示，响应式设计适配不同屏幕尺寸

## Assumptions

- 用户具有基本的网络连接能力
- 阿里云百炼API服务可用且稳定
- 用户理解短视频创作的基本概念
- 用户输入的创作主题是合理的（非恶意输入、非完全无关内容）
- 系统不需要用户身份认证（MVP阶段为匿名使用）
- 生成的内容不需要持久化存储（每次都是新的生成请求）
- 音乐风格建议仅提供文字描述，不提供实际音频文件或链接

## Out of Scope (MVP)

以下功能明确不在MVP范围内：

- 用户账户系统和登录功能
- 历史记录保存和查看功能
- 脚本编辑和自定义功能
- 实际音频文件播放或下载
- 多轮对话和上下文理解
- 内容审核和过滤功能
- 社交分享功能
- 数据分析和统计功能
- 移动端原生应用（仅Web应用）

## Dependencies

- 阿里云百炼平台API访问权限和API密钥
- 稳定的网络连接（用于API调用）
- 现代Web浏览器（支持ES6+和现代CSS特性）
