# Prompt Engineering Specification

**Date**: 2025-01-05  
**Feature**: 001-tiktok-creator-insight  
**Version**: 1.0  
**Status**: Draft - 待重构

## Overview

本文档定义了三个阶段的AI Prompt规范，目标是生成更贴合场景、更专业的内容。

## 设计原则

1. **场景化**：每个prompt应该明确场景和目标用户
2. **专业性**：使用行业术语和最佳实践
3. **结构化**：清晰的输出格式要求
4. **可执行性**：生成的内容应该可以直接用于拍摄和创作
5. **情感共鸣**：内容要有情感、有温度、有记忆点

## Stage 1: Hook Selection (金句选择)

### 当前Prompt分析

**位置**: `backend/src/services/stage1-hooks.ts`

**当前问题**:
- 描述较为通用，缺乏场景化指导
- 没有明确不同赛道/主题的差异化要求
- 缺乏对"金句"的专业定义和标准

### 重构目标

1. **明确角色定位**：定义"金句创作专家"的具体能力
2. **场景化要求**：根据不同主题/赛道提供差异化指导
3. **专业标准**：明确什么是"好金句"（3秒法则、情绪触发、记忆点等）
4. **输出质量**：确保每个金句都有明确的情绪锚点和记忆点

### 待设计的新Prompt结构

```
角色定义：
- 你是谁（短视频金句创作专家）
- 你的专业能力（3秒钩子、情绪触发、记忆点设计）

场景理解：
- 用户主题分析
- 目标受众识别
- 内容赛道判断

专业标准：
- 3秒钩子法则
- 情绪触发点设计
- 记忆点植入
- 语言节奏控制

输出要求：
- JSON格式
- 每个金句附带简要说明（为什么这个金句有效）
```

## Stage 2: Content Development (内容创作)

### 当前Prompt分析

**位置**: `backend/src/services/stage2-content.ts`

**当前问题**:
- 内容描述较为抽象（"丰富详细"、"有情感"等）
- 缺乏具体的创作框架和结构
- 没有明确不同内容类型的差异化要求

### 重构目标

1. **结构化框架**：明确内容创作的经典结构（引入→展开→升华）
2. **场景化描述**：要求生成具体的场景、画面、动作
3. **情感层次**：明确不同阶段的情感递进
4. **可拍摄性**：内容应该包含具体的拍摄指导

### 待设计的新Prompt结构

```
角色定义：
- 短视频内容创作专家
- 擅长将金句转化为可拍摄的内容

内容框架：
- 引入阶段：如何用金句开场，建立场景
- 展开阶段：如何展开故事/知识点，保持节奏
- 升华阶段：如何总结价值，留下记忆点

场景化要求：
- 具体场景描述（时间、地点、环境）
- 画面构图建议（镜头语言）
- 动作和互动设计
- 情绪递进路径

输出要求：
- JSON格式
- 每个要点包含：标题、详细内容、场景描述、情绪锚点
```

### 待补充内容

- [ ] 不同内容类型的创作框架（故事型、教程型、评测型）
- [ ] 场景描述的具体要素（五感描述、环境细节）
- [ ] 情绪递进的层次设计
- [ ] 可拍摄性的具体标准

## Stage 3: Script Conversion (脚本转换)

### 当前Prompt分析

**位置**: `backend/src/services/stage3-scripts.ts`

**当前问题**:
- 专业元素定义较为抽象
- 缺乏对不同脚本风格的具体要求
- 没有明确脚本的"可执行性"标准

### 重构目标

1. **专业元素细化**：每个专业元素的具体应用方法
2. **风格差异化**：明确三种脚本风格的独特要求
3. **可执行性**：脚本应该包含具体的拍摄指导和时间分配
4. **行业标准**：参考短视频行业的最佳实践

### 待设计的新Prompt结构

```
角色定义：
- 短视频拆解大师
- 擅长将内容转换为可执行的脚本

专业元素详解：
1. 情绪锚点 (Emotional Anchors)
   - 开场3秒：悬念钩子设计
   - 中段：情感共鸣点设计
   - 结尾：价值升华点设计

2. 记忆点植入 (Memory Points)
   - 金句重复策略
   - 视觉记忆点（道具、场景）
   - 听觉记忆点（音效、音乐）

3. 冲突设计 (Conflict Design)
   - 对比冲突（价格vs价值）
   - 反转冲突（预期vs现实）
   - 悬念冲突（问题vs答案）

4. 信息密度控制 (Information Density)
   - 前3秒：高密度信息（钩子+场景）
   - 中段：展开细节（节奏放缓）
   - 结尾：升华总结（信息收敛）

脚本风格要求：
1. 故事叙述型 (story)
   - 情节结构（起承转合）
   - 人物/场景设定
   - 情感弧线设计

2. 教程教学型 (tutorial)
   - 步骤清晰度
   - 实操演示点
   - 知识点拆解

3. 对比评测型 (comparison)
   - 对比维度设计
   - 评测标准明确
   - 结论推导逻辑

可执行性要求：
- 时间分配建议（每个部分建议时长）
- 镜头语言建议（特写、中景、全景）
- 动作指导（演员/创作者的动作）
- 道具/场景要求

输出要求：
- JSON格式
- 每个脚本包含完整的专业元素
- 每个要点附带时间分配和拍摄建议
```

### 待补充内容

- [ ] 不同脚本风格的具体案例和模板
- [ ] 时间分配的最佳实践（15秒、30秒、60秒）
- [ ] 镜头语言的行业术语和标准
- [ ] 情绪锚点的具体设计方法

## 通用改进方向

### 1. 角色定位更专业

- 从"专家"升级为"大师"或"拆解师"
- 明确专业背景（如"10年短视频创作经验"）
- 强调方法论和体系化思维

### 2. 场景理解更深入

- 分析用户主题的深层需求
- 识别目标受众特征
- 判断内容赛道特点

### 3. 输出要求更具体

- 明确字数要求（如"不少于100字"）
- 明确结构要求（如"必须包含4个要点"）
- 明确质量标准（如"必须有具体场景描述"）

### 4. 行业术语和最佳实践

- 使用短视频行业的专业术语
- 参考头部创作者的最佳实践
- 融入平台算法偏好（如完播率、互动率）

## 重构完成总结

### Stage 1: Hook Selection ✅

**重构亮点**：
1. **角色定位升级**：从"短视频创作专家"升级为"拥有10年经验的金句创作大师"
2. **场景化分析**：添加了内容赛道识别、目标受众特征、情绪触发点分析
3. **专业标准细化**：
   - 3秒钩子法则（前3秒必须抓住注意力）
   - 情绪触发点设计（好奇、共鸣、反差、悬念、惊喜）
   - 记忆点植入（语言节奏、独特视角、具体细节）
   - 场景适配性（与主题相关、适合短视频表达、可延展性强）
4. **输出要求明确**：金句长度控制在15-25字，确保差异化

### Stage 2: Content Development ✅

**重构亮点**：
1. **结构化框架明确**：引入→展开→升华的经典结构
2. **场景化描述标准**：
   - 五感描述（视觉、听觉、嗅觉、味觉、触觉）
   - 环境细节（光线、温度、声音、氛围）
   - 时间感（明确的时间节点或时间流逝感）
3. **可拍摄性要求**：
   - 镜头语言建议（特写、中景、全景、运动镜头）
   - 动作指导（具体的动作和互动）
   - 道具/场景要求
4. **情感层次设计**：三个要点形成清晰的情绪弧线
5. **字数要求提升**：引入和升华阶段不少于150字，展开阶段不少于200字

### Stage 3: Script Conversion ✅

**重构亮点**：
1. **专业元素详解**：
   - 情绪锚点：开场3秒、中段、结尾的具体设计
   - 记忆点植入：金句重复、视觉记忆点、听觉记忆点、反差记忆点
   - 冲突设计：对比、反转、悬念的具体应用
   - 信息密度控制：前3秒高密度、中段中密度、结尾低密度
2. **风格差异化明确**：
   - 故事叙述型：起承转合结构、人物/场景设定、情感弧线
   - 教程教学型：步骤清晰度、实操演示点、知识点拆解
   - 对比评测型：对比维度设计、评测标准明确、结论推导逻辑
3. **可执行性要求**：
   - 时间分配建议（总时长、每个要点时长、关键时间节点）
   - 镜头语言建议（镜头类型、切换时机、画面构图）
   - 动作指导（创作者/演员动作、道具使用、场景布置）
4. **输出要求提升**：
   - description 不少于150字
   - conflictDesign 和 informationDensity 不少于100字
   - emotionalAnchors 至少3个（开场、中段、结尾）
   - memoryPoints 至少3个（金句重复、视觉、反差等）

### 整体改进

1. **专业性提升**：从"专家"升级为"大师"，强调经验和专业能力
2. **场景化增强**：每个阶段都添加了场景分析和适配要求
3. **可执行性**：所有Prompt都强调可拍摄、可执行的具体要求
4. **结构化**：明确的结构框架和输出格式要求
5. **行业标准**：融入短视频行业的最佳实践和术语
